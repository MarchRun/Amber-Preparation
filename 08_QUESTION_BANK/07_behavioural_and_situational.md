**Purpose:** Fifteen original bilingual questions with honest evidence boundaries.

### Q-BEH-01 — Team contribution

| Field | Value |
|---|---|
| **Category** | Behavioural and situational |
| **Sub-skill** | Teamwork |
| **Difficulty** | Foundation |
| **Asked in** | HR / technical |
| **Question (EN)** | What was your role in a real development team? |
| **Pertanyaan (ID)** | Apa peran Anda dalam tim pengembangan yang nyata? |
| **What is assessed** | Clear personal contribution. |
| **Evidence basis** | CV internship; portfolio page 3. |
| **Strong answer outline** | Four-person team; backend role; stack; coordination; no invented delivery metrics. |
| **Model answer (EN)** | At Bappenas I was a backend developer intern in a four-person internship team. The portfolio describes a project manager, system analyst, frontend developer and my backend role. I developed backend features using PHP, CodeIgniter and MySQL and coordinated with team members and cross-department stakeholders. That is the scope I can support from my documents. I would add a specific feature example from memory rather than claim the entire team's work as mine. |
| **Contoh jawaban (ID)** | Di Bappenas saya menjadi backend developer intern dalam tim magang beranggotakan empat orang. Portofolio menjelaskan peran project manager, system analyst, frontend developer dan saya di backend. Saya mengembangkan fitur memakai PHP, CodeIgniter dan MySQL serta berkoordinasi dengan anggota tim dan pemangku kepentingan lintas departemen. Itulah lingkup yang didukung dokumen. Saya akan menambahkan contoh fitur asli dari ingatan, bukan mengklaim seluruh pekerjaan tim sebagai kontribusi saya sendiri. |
| **Follow-up** | Which handoff to another role can you describe precisely? |
| **Weak answer / red flag** | Uses only "we" or claims team leadership without evidence. |
| **Scoring anchor** | 1 = inflated ownership · 3 = accurate role · 5 = verified action and handoff with clear boundary |
