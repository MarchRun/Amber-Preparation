## 1. What is tested

Criteria describes verbal ability as reading comprehension, logic, and attention to detail, measured through sentence completion, vocabulary, and word comparison.

Sub-types:
1. Synonyms
2. Antonyms
3. Analogies
4. Sentence completion
5. Odd word out
6. Syllogisms / logical statements
7. Attention to detail (string matching)

## 2. Core strategy

### For vocabulary items
- Read the target word in context if one is given.
- Predict the answer before looking at options.
- Eliminate options with the wrong charge (positive/negative) or intensity.
- If you do not know the word, use roots, prefixes, and suffixes.

Common prefixes:
| Prefix | Meaning | Example |
|---|---|---|
| bene- | good | benevolent |
| mal- | bad | malicious |
| circum- | around | circumvent |
| contra- | against | contradict |
| hyper- | over | hyperbole |
| hypo- | under | hypothetical |
| inter- | between | intervene |
| intra- | within | intramural |
| pre- | before | precede |
| post- | after | postpone |
| pro- | forward/for | promote |
| retro- | backward | retroactive |
| sub- | under | subordinate |
| super- | above | superfluous |
| trans- | across | transient |

Common suffixes:
| Suffix | Meaning |
|---|---|
| -able/-ible | capable of |
| -al | relating to |
| -fy | to make |
| -ism | belief/practice |
| -ist | person who |
| -ity | state of |
| -ous | full of |
| -tion | act/process |

### For analogies
Identify the relationship before looking at options:
- Function: "knife : cut"
- Category: "rose : flower"
- Part-whole: "wheel : car"
- Cause-effect: "rain : flood"
- Degree: "warm : hot"
- Opposite: "hot : cold"
- Person-object: "author : book"
- Tool-material: "sculptor : clay"
- Sequence: "spring : summer"

Then test each option with the same relationship. Beware of options that match the topic but not the relationship.

### For sentence completion
- Read the entire sentence.
- Identify the logical signal: contrast (`although`, `despite`), cause (`because`, `therefore`), addition (`and`, `moreover`), sequence (`before`, `after`).
- Predict a word.
- Choose the closest option.
- Check grammar and tone.

### For syllogisms
Translate to sets. Use these rules:
- All A are B → A is inside B.
- No A are B → A and B do not overlap.
- Some A are B → at least one overlap.
- "Some" does not imply "some are not."
- "All" does not establish existence. Infer "some" only when existence is stated or logically established; follow any explicit test convention instead of inventing one.

Valid patterns:
- All A are B; all B are C → all A are C.
- All A are B; X is A → X is B.
- No A are B; X is A → X is not B.
- Some A are B → some B are A.
- All A are B; some C are A → some C are B.

Invalid patterns:
- Some A are B; some B are C → some A are C. (Not necessarily.)
- All A are B; all C are B → all A are C. (Not necessarily.)
- No A are B; no C are B → no A are C. (Not necessarily.)

### For attention to detail
- Compare in chunks (first 4 characters, then next 4).
- Check case, spacing, punctuation, and digit/letter swaps (0/O, 1/l/I).
- Do not rely on overall shape.

## 3. Worked examples

### V-EX-01 — Antonym
**Question:** Choose the word most nearly opposite to **SCARCE**.
A) rare B) abundant C) expensive D) limited E) hidden
**Answer:** B) abundant.
**Why:** Scarce means insufficient or hard to find; abundant means plentiful.
**Trap:** "Rare" is a synonym, not an antonym.

### V-EX-02 — Synonym
**Question:** Choose the word most nearly similar to **CANDID**.
A) secretive B) frank C) cautious D) bitter E) formal
**Answer:** B) frank.
**Why:** Candid means honest and direct.
**Trap:** "Cautious" is plausible in tone but not meaning.

### V-EX-03 — Analogy
**Question:** Thermometer : Temperature :: Barometer : ?
A) humidity B) pressure C) wind D) altitude E) rainfall
**Answer:** B) pressure.
**Why:** A thermometer measures temperature; a barometer measures atmospheric pressure.

### V-EX-04 — Sentence completion
**Question:** The manager requested a ____ report, with no unnecessary detail, and recommendations that were ____ enough to implement immediately.
A) verbose / vague B) concise / practical C) incomplete / contradictory D) lengthy / unusable E) redundant / obscure
**Answer:** B) concise / practical.
**Why:** No unnecessary detail means concise; ready to implement means practical. Both clues support B. Practice items should have a single defensible best answer, not be deliberately ambiguous.

### V-EX-05 — Odd word out
**Question:** Which word does not belong?
A) copper B) iron C) silver D) plastic E) gold
**Answer:** D) plastic.
**Why:** The others are metals.

### V-EX-06 — Syllogism
**Question:** All engineers are problem solvers, and at least one engineer exists. Some problem solvers are artists. Which conclusion must be true?
A) All artists are engineers.
B) Some engineers are artists.
C) Some problem solvers are engineers.
D) No artists are engineers.
**Answer:** C.
**Why:** "All engineers are problem solvers" means every engineer is in the problem-solver set, so at least some problem solvers are engineers. B is not guaranteed because the artists who are problem solvers may not be engineers.

### V-EX-07 — Conditional logic
**Question:** If the server is down, the website is unavailable. The website is available. What follows?
A) The server is down.
B) The server is not down.
C) The website is slow.
D) The server is being repaired.
**Answer:** B.
**Why:** This is modus tollens: P → Q; not Q; therefore not P.

### V-EX-08 — Attention to detail
**Question:** Which pair is exactly identical?
A) `INV-2049-A7` / `INV-2049-A7`
B) `INV-2049-A7` / `INV-2049-A1`
C) `1NV-2049-A7` / `INV-2049-A7`
D) `INV-2049-A7` / `INV-2049-A7 `
**Answer:** A.
**Why:** B changes the last character; C uses the digit 1 instead of the letter I; D has a trailing space.

## 5. Practice drill (8 items, 4 minutes)

1. Antonym of **OBSOLETE**: A) current B) broken C) ancient D) useful E) rare
2. Synonym of **PRUDENT**: A) reckless B) cautious C) wealthy D) hesitant E) strict
3. Analogy: **Sculptor : Clay :: Poet : ?** A) word B) pen C) poem D) paper E) rhythm
4. Sentence: "The data was ____, so the team could not draw a reliable conclusion." A) conclusive B) insufficient C) abundant D) consistent E) transparent
5. Odd one out: A) square B) circle C) triangle D) cube E) rectangle
6. All managers are employees, and at least one manager exists. Some employees work remotely. Which must be true? A) Some managers work remotely. B) All remote workers are managers. C) Some employees are managers. D) No managers work remotely.
7. If it rains, the event is cancelled. The event was not cancelled. Therefore: A) it rained B) it did not rain C) the event was indoors D) the forecast was wrong
8. Which pair is identical? A) `AX-7734-B` / `AX-7734-8` B) `AX-7734-B` / `AX-7734-B` C) `AX-7734-B` / `AX-7734-B ` D) `AX-7734-B` / `AX-7734-b`

**Answers:** 1-A, 2-B, 3-A (creator to medium: clay/words, not the finished poem), 4-B, 5-D (3D vs. 2D), 6-C, 7-B, 8-B.

## 7. Common mistakes

- Choosing a synonym when the question asks for an antonym.
- Matching topic instead of relationship in analogies.
- Overreading sentence completion and missing the contrast signal.
- Assuming "some" means "some but not all."
- Rushing attention-to-detail items and missing one character.
- Spending 40 seconds on a vocabulary word you either know or don't.
