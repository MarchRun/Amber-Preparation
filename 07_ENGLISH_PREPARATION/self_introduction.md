# Self-Introduction

**Purpose:** Three lengths with clear ownership and honest limits.
**Created / last updated:** 31 October 2026
**Grounding:** CV page 1; portfolio pages 3, 7–10. Timings are rehearsal targets, not guarantees.

## 1. About 45 seconds

"Good morning. My name is Marchel Karuna Kwee. / I graduated in Informatics Engineering from Institut Teknologi Sumatera with a GPA of 3.60. / I worked as a backend developer intern at Bappenas, using PHP, CodeIgniter and MySQL in a four-person team. / My portfolio also includes a Sunday school web application built with Next.js, TypeScript, PostgreSQL and Supabase, including RFID attendance integration. / I would like to bring that web-development foundation to this programmer role and develop my enterprise software skills."

`/` means a short pause, not a word. The last sentence is a proposed motivation—use it only if true.

## 2. About 90 seconds

"Good morning. My name is Marchel Karuna Kwee. I graduated in Informatics Engineering from Institut Teknologi Sumatera in July 2026, with a GPA of 3.60. My studies focused on software engineering and information systems.

During my backend development internship at Kementerian PPN/Bappenas, I developed features for an internal system using PHP, CodeIgniter and MySQL. I worked in a four-member internship team and coordinated with team members and cross-department stakeholders. We used Agile development, Jira and GitLab.

In my portfolio, SMB Suvanna Dipa is a Sunday school web application. My role was full-stack developer. The stack was Next.js, TypeScript, PostgreSQL and Supabase. I developed operational features for student, mentor and admin roles and integrated the application with an RFID attendance system. I would keep my web-integration contribution separate from hardware work.

I also have project experience in cloud deployment and project planning. This role interests me because it could connect my web-development foundation with broader enterprise problems. I have not used all the advertised platforms, so I would be honest about those gaps and learn through small, reviewed tasks."

## 3. About two minutes

Use the 90-second version and add before the closing:

"For Iterary, a library management PWA, my role was cloud engineer. I configured the cloud environment, application deployment, supporting services, automated deployment workflow and traffic routing. The project lists Docker, Google Cloud, MySQL and Redis among its technologies.

For Kibang Soil Tracker, I was project manager. I led planning and prepared specifications, budget, risk and testing documentation. I also contributed to frontend work, database integration and sensor testing. These roles gave me different perspectives on software delivery, but I would not describe student project management as professional management of engineers."

Do not exceed the requested length just to include every project. If interrupted, answer the question immediately.

## 4. Delivery notes / catatan ID

- Tekankan **my role was** supaya kontribusi pribadi jelas.
- Sebut GPA perlahan: "three point six zero". Jangan gabungkan nama semua teknologi tanpa jeda.
- Gunakan "the project lists" jika detail penggunaan layanan belum bisa dijelaskan dari ingatan.
- Tidak perlu meminta maaf atas bahasa Inggris. Minta klarifikasi jika makna belum jelas.
- Jangan menyebut final-year project jika konteks akademiknya belum dikonfirmasi dari dokumen tambahan.

## 5. Six likely follow-ups

| Question | Safe response direction |
|---|---|
| What exactly did you own? | Name the documented role/responsibility; add one verified implementation detail from memory |
| Did you build the RFID hardware? | Explain only the web integration; do not claim hardware ownership |
| What was the result? | Describe the documented feature/system; no invented user count or efficiency percentage |
| What did you find hardest? | Supply a real event first; no documented event exists in the CV |
| Why this company? | Public service portfolio + a genuine interest; do not claim inside knowledge |
| Can you work in Java or .NET? | No evidenced project experience; map OOP/API/SQL concepts and propose a small learning task |

## 6. Fill-in template

"I am [name/degree]. My professional exposure is [internship, dates, scope]. One relevant project is [name], where my role was [role]. I personally [documented action]. I did not own [boundary]. I am interested in [truthful reason]. I would need to develop [honest gap]."

**Do not say:** "I am fluent"; "I designed everything"; "I built the RFID hardware"; "I already know all five stacks"; "I reduced work by 80%"; "I can start immediately" unless personally confirmed.
