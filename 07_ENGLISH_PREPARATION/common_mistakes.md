# Common English and Credibility Mistakes

**Purpose:** Repair meaning with simple sentences.
**Created / last updated:** 31 October 2026
**Status:** Practice examples, not observed candidate errors.

## When you do not understand

Stop → identify the unclear phrase → ask one specific question → restate the answer → proceed. If you missed the whole question: "Could you repeat the question a little more slowly?" If only one term is unclear: "What does X refer to in this case?" Do not ask for repetition while already giving a contradictory answer.

## Repair phrases

- "Let me rephrase that more simply."
- "I need to correct one detail: I integrated the web side."
- "That was a proposed improvement, not a measured result."
- "I do not have a verified example of that incident. I can explain how I would approach it."
- "I cannot confirm that from the public information."

Before rehearsing any answer, underline past-tense claims. For each one, ask: Is this in the CV/portfolio or a real event Marchel can explain? If not, remove it or make it explicitly hypothetical.
