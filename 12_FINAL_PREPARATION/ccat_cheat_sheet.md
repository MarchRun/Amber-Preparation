# CCAT Preparation Cheat Sheet

**Created / last updated:** 31 October 2026
**Purpose:** Review before starting; close during the assessment unless allowed.

Standard Criteria format: up to 50 items/15 minutes, verbal/math-logic/spatial, no calculator. Amber's exact administration is unconfirmed. Read on-screen rules and navigation before the timer starts.

**Pace:** 900 seconds/50 = 18 seconds per item if finishing. Use a flexible roughly 20-second decision limit. Forward-only: guess and advance; do not plan to return. In the final minutes, reduce time spent on each hard item, not automatically abandon all solving. Submit a best guess rather than leave a reached item blank when there is no penalty.

| Topic | Shortcut |
|---|---|
| Percentage | p% of x = px/100 |
| Reverse discount | Original = final/(1−discount) |
| Successive change | Multiply factors; +20%, −20% gives 0.96 |
| Ratio | Total parts first; convert one part |
| Average | Total/n; combine using weights |
| Speed | Distance/time; overall speed = total distance/total time |
| Work | Equal worker rates: workers × time constant |
| Series | Differences, ratios, alternating terms before complex rules |
| Logic | P→Q and not Q imply not P; Q alone does not imply P |
| Sets | All A are B does not establish that A exists |
| Rotation | 90° CCW: (x,y)→(−y,x); clockwise: (y,−x) |
| Painted cube | Interior (n−2)³ for n≥2; corners 8 |

Analogies: name the relationship before choosing. Vocabulary: check whether synonym or antonym. Spatial: track one feature and distinguish mirror from rotation.

Local mock scores are not CCAT percentiles. Published provider norms are not national statistics or Amber's pass marks. Sleep and calm pacing matter more than memorising answers to burned practice items.
