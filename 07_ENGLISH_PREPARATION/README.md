# English Preparation

**Purpose:** Be understandable, accurate and calm—not artificially fluent.
**Created / last updated:** 31 October 2026
**Evidence:** CV self-rating is Limited Working Proficiency; actual speaking/reading/writing performance is unmeasured.

| File | Rehearsal |
|---|---|
| `self_introduction.md` | Record 45-second then 90-second introduction |
| `technical_communication.md` | Explain one actual project and one hypothetical improvement |
| `behavioural_answers.md` | Fill missing real incidents before practising STAR |
| `business_case_language.md` | Present a fictional case using simple signposts |
| `pronunciation_and_fluency.md` | Ten minutes of targeted aloud practice |
| `common_mistakes.md` | Repair misunderstood meaning without repeated apologies |
| `ready_to_say_fallbacks.md` | Speakable honest replies when a metric, incident or ownership detail is not established |

**30-minute routine:** 5 pronunciation; 5 introduction without reading; 8 project explanation plus two follow-ups; 7 case/behaviour answer; 5 listen and re-record the weakest 30 seconds. Review meaning, pace and unsupported claims before grammar polish.

Likely risks are a hypothesis: long memorised sentences, translating while speaking and misunderstanding follow-ups. Do not assume reading is strong or speaking is weak solely from the CV label. Record a sample and update `../09_MOCK_ASSESSMENTS/english_interview/score_report.md`.

Scripts are drafts, not biography beyond the documented facts. Preferences and plans must be confirmed by Marchel. A placeholder for an incident must never be read as if it happened. No real failure, conflict, quantified result or readiness to relocate has been established.
