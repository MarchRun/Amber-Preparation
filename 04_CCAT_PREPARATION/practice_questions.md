# CCAT Mixed Practice Drills

**Purpose:** Short, repeatable drills for the three CCAT domains. Use between full mocks.
**Created:** 31 October 2026
**Items:** 30 (10 verbal, 12 numerical, 8 spatial)
**Suggested time:** 10 minutes for all 30; 3 minutes for each block
**Answer key:** End of this file

---

## How to use

- Do **one block at a time** if you are learning the method.
- Do **all 30 in 10 minutes** if you are training pace.
- Write answers on paper. Do not annotate the questions on the first pass.
- After scoring, classify every error as knowledge, careless, panic, or time (see `answer_keys.md`).
- Re-do a block after 48 hours. If you only remember the answer, the drill has stopped being useful.

## Block A — Verbal (10 items, 3 minutes)

**A1.** Choose the word most nearly similar to **DILIGENT**.
A) lazy
B) hardworking
C) intelligent
D) cautious
E) friendly

**A2.** Choose the word most nearly opposite to **TENTATIVE**.
A) provisional
B) definite
C) hesitant
D) initial
E) flexible

**A3.** Library : Books :: Gallery : ?
A) artists
B) paintings
C) visitors
D) frames
E) tickets

**A4.** The instructions were ___, so the team had to guess what the client wanted.
A) explicit
B) ambiguous
C) concise
D) detailed
E) mandatory

**A5.** All nurses are carers, and at least one nurse exists. Some carers are men. Which conclusion must be true?
A) Some nurses are men.
B) All men are carers.
C) Some carers are nurses.
D) No nurses are men.
E) All carers are nurses.

**A6.** If the server is down, the website is unavailable. The website is available. What follows?
A) The server is down.
B) The server is not down.
C) The website is slow.
D) The server is being repaired.
E) Nothing follows.

**A7.** Which word does not belong?
A) inch
B) metre
C) kilogram
D) mile
E) yard

**A8.** Which pair is exactly identical?
A) `QX-441-Z` / `QX-441-Z`
B) `QX-441-Z` / `QX-441-2`
C) `QX-441-Z` / `QX-441-Z ` (trailing space)
D) `QX-441-Z` / `QX-44I-Z` (capital I)
E) `QX-441-Z` / `QX-441-z`

**A9.** Oak acorn : Oak tree :: Sparrow egg : ?
A) nest
B) bird
C) shell
D) hen
E) food

**A10.** Despite the ___ weather, the outdoor event was ___.
A) terrible / well attended
B) pleasant / enjoyable
C) mild / comfortable
D) warm / outdoors
E) fine / crowded

## Block C — Spatial (8 items, 3 minutes)

**C1.** An arrow points west. It is rotated 90° clockwise. In which direction does it now point?
A) north
B) south
C) east
D) west
E) northwest

**C2.** A square sheet is folded in half vertically, then in half horizontally. Three small, separate holes are punched through all layers, away from folds and edges and without overlaps after unfolding. How many holes appear when unfolded?
A) 3
B) 6
C) 9
D) 12
E) 16

**C3.** Fold the following net into a cube. Which face is opposite face 2?
```text
   [5]
[1][2][3][4]
   [6]
```
A) face 1
B) face 3
C) face 4
D) cannot be determined
E) none

**C4.** A 4 × 4 × 4 cube is painted on all outer faces and cut into 64 unit cubes. How many unit cubes have exactly three painted faces?
A) 4
B) 6
C) 8
D) 12
E) 16

**C5.** A 2 × 2 × 2 cube is painted on all outer faces and cut into 8 unit cubes. How many unit cubes have at least one painted face?
A) 0
B) 4
C) 6
D) 8
E) 12

**C6.** Point (4, −2) is rotated 90° counter-clockwise about the origin. What are its new coordinates?
A) (2, 4)
B) (−2, 4)
C) (2, −4)
D) (−4, 2)
E) (4, 2)

**C7.** A rectangular sheet measures 12 cm by 9 cm. A 2 cm × 2 cm square is cut from each corner, and the sides are folded up into an open box. What is the volume?
A) 60 cm³

C) 80 cm³
D) 96 cm³
E) 108 cm³

**C8.** Which capital letter looks unchanged when reflected in a vertical mirror?
A) M

## Answer key

### Block A

| Item | Answer | Explanation |
|---|---|---|
| A1 | B | Diligent means hardworking. |
| A2 | B | Tentative means provisional; definite is the opposite. |
| A3 | B | A library contains books; a gallery contains paintings. |
| A4 | B | Ambiguous means unclear, which forces guessing. |
| A5 | C | All nurses are carers, so at least some carers are nurses. The men may be outside the nurse subset. |
| A6 | B | Modus tollens: down → unavailable; available → not down. |
| A7 | C | Kilogram measures mass; the others measure length or distance. |
| A8 | A | B changes the final character, C adds a space, D substitutes I, E changes case. |
| A9 | B | An oak acorn develops into an oak tree; a sparrow egg can develop into a bird, not a hen. |
| A10 | A | "Despite" signals contrast: bad weather but good attendance. |

### Block B

| Item | Answer | Explanation |
|---|---|---|
| B1 | C | 160 × 0.25 = 40. |
| B2 | C | 72 ÷ 0.30 = 240. |
| B3 | C | Difference 2 parts = 14, so 1 part = 7; total 8 parts = 56. |
| B4 | C | Total = 7 × 12 = 84; 84 − 65 = 19. |
| B5 | C | Speed = 75 km/h; 450 ÷ 75 = 6 hours. |
| B6 | C | Differences +5, +7, +9, +11, then +13: 38 + 13 = 51. |
| B7 | D | Double each term: 16 × 2 = 32. |
| B8 | D | Perfect cubes: 1, 8, 27, 64, 125. |
| B9 | C | 6 × 10 = 60 worker-days; 60 ÷ 5 = 12 days. |
| B10 | C | 500,000 × 1.20 × 0.90 = 540,000. |
| B11 | B | 200,000 × 0.90 = 180,000. |
| B12 | D | 300 × 0.45 = 135. |

### Block C

| Item | Answer | Explanation |
|---|---|---|
| C1 | A | West rotated 90° clockwise points north. |
| C2 | D | Four layers × three holes = 12. |
| C3 | C | In a four-square band, faces two apart are opposite: 1–3 and 2–4. |
| C4 | C | Three painted faces occur only at the eight corners. |
| C5 | D | Every cube in a 2 × 2 × 2 is a corner cube, so all 8 are painted. |
| C6 | A | (x, y) → (−y, x): (4, −2) → (2, 4). |
| C7 | C | Base 8 × 5, height 2; volume = 80 cm³. |
| C8 | A | "M" has vertical symmetry. |
