## 2. Patterns across Amber job ads

### 2.1 Fresh Graduate Programmer (archived)
Requirements:
- Recent IT graduate.
- Passion for programming.
- Solid basic programming concepts, SQL beyond `SELECT *`.
- Interest in Java, PHP, Angular, .NET, Flutter.
- Resourcefulness and research ability.
- Judgment about when to ask for help.
- Growth mindset and feedback orientation.
- "Harmony between brain and heart."

### 2.2 Fresh Graduate Business Analyst (archived)
Requirements:
- Business requirement analysis / user stories.
- Involvement in design and testing.
- Internship as BA/System Analyst/Functional Consultant is a plus.
- Knowledge of software development methodology.
- Dynamic, result-oriented team player.
- "Decent English."

### 2.3 Programmer (.NET) (archived)
Requirements:
- Bachelor's in IT or equivalent.
- Passion for programming and continuous learning.
- Familiarity with Microsoft 365, Power Platform, Azure is an advantage.
- English proficiency preferred.
- Strong common sense and problem solving.
- "We don't need superstars, we need super team."

### 2.4 Java Backend Developer / Full Stack Developer (observed)
- Java/Spring, PHP, Next.js, FastAPI/Python, MySQL.
- Experience levels vary (1–3 years, 3–5 years).
- English often listed.

## 4. Likely evaluator archetypes

| Evaluator | Cares about | How to satisfy |
|---|---|---|
| HR/recruiter | Motivation, fit, communication, contract terms | Clear story, honest interest, no red flags |
| Technical lead | Fundamentals, debugging, learning ability | Correct concepts, admit gaps, show method |
| Consultant/BA | Requirement clarity, business value, client handling | Ask questions, structure, trade-offs |
| Manager | Reliability, ownership, attitude | Examples of delivery and accountability |

You may face a panel. Address answers to the person who asked, but keep the others included.

## 6. Process risks

| Risk | Signal | Mitigation |
|---|---|---|
| Hidden coding test | Invitation says "business case" but interviewer asks to code | Clarify language and scope early |
| Group case | Multiple candidates join | Establish structure, invite others, don't dominate |
| Rapid-fire technical questions | No time to prepare | Use concise definitions + one example |
| English fluency check disguised as chat | Informal conversation | Treat every interaction as assessed |
| Pressure test | Interviewer challenges assumptions | Restate constraint, adapt, don't argue |
| Contract mismatch | Role differs from ad | Ask clarifying questions before accepting |

## 7. Questions the candidate should be ready to ask

Choose two depending on stage:

1. "Could you tell me more about the first project a fresh graduate usually joins?"
2. "How is the first three months structured in terms of mentoring and review?"
3. "What technology stack would I likely start with?"
4. "What does success look like at the end of the contract?"
5. "How does the team balance client deadlines with learning time?"

Avoid asking about salary or leave in the first assessment unless the interviewer raises it.

| 3–5 days | Follow up politely if no response |
