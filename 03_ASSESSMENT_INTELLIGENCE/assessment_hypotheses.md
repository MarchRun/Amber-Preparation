# Assessment Hypotheses

**Purpose:** Make assumptions explicit, testable, and easy to discard.
**Created:** 31 October 2026
**Last updated:** 31 October 2026
**Method:** Hypothesis-driven research; each hypothesis has evidence, probability, implications, and disconfirming signals.

---

## H-01 — The CCAT is the standard Criteria 50/15 test

| Field | Content |
|---|---|
| Probability | 80% |
| Evidence for | Name matches Criteria's trademarked assessment; standard format is 50 items/15 minutes; company has no public custom cognitive test |
| Evidence against | None found; employer could use a variant or a different provider |
| Implication | Train at 50Q/15min; expect verbal, math/logic, spatial |
| Disconfirming signal | On-screen instructions show a different count/time or no spatial items |
| Response if wrong | Recalculate pace: time ÷ questions; prioritise easy items |

## H-02 — CCAT is a hard screening gate

| Field | Content |
|---|---|
| Probability | 75% |
| Evidence for | Placed first in a 4.5-hour agenda; common practice for graduate hiring; cognitive tests are cheap filters |
| Evidence against | Some companies use it descriptively, not as a cut-off |
| Implication | Do not treat it as a warm-up; prepare seriously |
| Disconfirming signal | Interviewer says "this is just for our records" |
| Response | Still do your best; assume it matters |

## H-03 — The business case is discussion/written, not a full coding test

| Field | Content |
|---|---|
| Probability | 55% |
| Evidence for | Title says "Business Case," not "Coding Test"; consultancy role; mixed evaluators; 4.5-hour agenda leaves time for discussion |
| Evidence against | "Programmer" role may include a practical coding component; the ad emphasises programming |
| Implication | Prepare structured analysis and spoken explanation; keep basic coding sharp |
| Disconfirming signal | You are asked to open an IDE or shared editor |
| Response | Clarify language/scope; pseudocode first; deliver a thin working solution |

## H-07 — The role will assign one primary stack, not all five

| Field | Content |
|---|---|
| Probability | 70% |
| Evidence for | No one uses Java, PHP, Angular, .NET, and Flutter equally; projects drive assignment; "interested in learning" signals adaptability |

## Hypothesis review protocol

- ✅ Confirmed
- ❌ Disconfirmed
- ◐ Partially confirmed
- ? Still unknown

Update `../RESEARCH_LOG.md` with authorised non-confidential observations, not protected assessment content.
