# How to Record a Score — Fictional Example

**Created:** 1 November 2026
**Status:** Invented teaching data. NOT Marchel's results, not provider norms and not Amber's hiring threshold.

## 1. Cognitive arithmetic example

A fictional learner reaches all 50 questions in a 15-minute practice. At submission time they mark 35 as solved/informed-elimination attempts and 15 as blind guesses. Of the first group 25 are correct; of the second 3 are correct.

| Metric | Calculation | Example result |
|---|---|---:|
| Submitted | 35 + 15 | 50 |
| Raw correct | 25 + 3 | 28/50 |
| Accuracy on all submissions | 28/50 | 56% |
| Substantive accuracy | 25/35 | 71.4% |
| Correct blind guesses | Record separately | 3/15 |
| Unanswered | 50 − 50 | 0 |

All lucky guesses count toward raw score, but not toward substantive accuracy. The source of a correct answer must be marked when answering, not reclassified afterwards to improve the statistic. No percentile follows from this local mock.

Useful conclusion: the learner combines some accurate methods with many guesses. Review category-specific time and errors before deciding between knowledge practice and pacing practice. Merely reaching question 50 does not show 50 substantive attempts.

## 2. Technical observation example

Weak note: "SQL was fine, 4/5."

Better note: "On a department-headcount task the learner used LEFT JOIN but COUNT(*), reporting one employee for an empty department. After a hint they changed to COUNT(employee_id). Independent result is incorrect; hint-assisted correction is recorded separately. Next drill: explain the null-extended row and test zero/one/many employees."

This identifies task, exact defect, assistance and a retest. Do not award independent correctness retroactively.

## 3. Spoken observation example

Weak note: "English needs improvement."

Better note: "During the two-minute project explanation, the listener understood the goal and stack but could not tell which integration was personally owned. The learner clarified the web contribution after one follow-up. Next drill: add an explicit 'My role was...' sentence, then answer a hardware-boundary question without reading."

That is evidence about clarity and ownership, not a judgement about accent. Any actual rating requires the actual recording/response; these sentences are examples only.

## 4. Keep the conclusion bounded

Record what the task demonstrated, where it failed and one next action. Do not label the learner "strong junior" from one rehearsed answer or predict a hiring outcome. Use [the actual index](result_index.md) only when a real attempt occurs.
