## Local practice interpretation — no score conversion

These sets are unnormed and not equivalent to CCAT. The table is only a way to organise review of these items, not a performance classification against other candidates. No score converts to a provider percentile, IQ or hiring probability.

| Correct / 50 | Interpretation | Next action |
|---:|---|---|
| 0–19 | Pace or foundational gap | Re-read category guides; do untimed drills, then sprint |
| 20–27 | Review missed methods and time use | Drill the observed weak skill |
| 28–34 | Personal drill-goal range | Compare raw score and substantive accuracy |
| 35–42 | Many local items correct | Check freshness/familiarity, then shift to other stages |
| 43–50 | Most local items correct | Do not infer a provider score; use fresh material |

For the 30-question sprint:

| Correct / 30 | Interpretation |
|---:|---|
| 0–11 | Foundation gap; untimed practice first |
| 12–17 | Pace gap; repeat sprint |
| 18–23 | Review remaining local errors |
| 24–30 | Most local sprint items correct; check familiarity |

## Error diagnosis

For every wrong answer, assign exactly one cause:

| Code | Cause | Fix |
|---|---|---|
| K | Did not know the concept | Re-read the relevant guide section |
| C | Careless arithmetic or misread | Slow down 2 seconds on the operation; underline the question |
| P | Panic guess | Practise the 15-second skip rule |
| T | Time ran out | Sprint drills; attempt easier items first |
| A | Ambiguous item | Note it; do not count it against yourself |

If time/panic errors dominate, practise triage, but investigate why: unfamiliar concepts and reading effort can also cause slow decisions. Do not diagnose the bottleneck from the last question reached alone.
