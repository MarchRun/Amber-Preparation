# Learning Resources

**Purpose:** Select a few authoritative references without buying last-minute confidence.
**Created / last updated:** 31 October 2026

`ccat_resources.md` prioritises official format and free samples. `technical_resources.md` lists official documentation. `english_resources.md` supports listening/pronunciation. New recommendations are not presented as pages freshly retrieved during this continuation; earlier company/Criteria retrieval evidence is in `../RESEARCH_LOG.md`.

Use at most 20–30 minutes of reference reading before active practice. Avoid sites promising Amber questions, guaranteed CCAT scores, leaked material or unsupported percentile conversions. Do not paste the candidate's personal documents into untrusted preparation services.
