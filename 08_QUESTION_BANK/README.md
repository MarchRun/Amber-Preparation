## How to rehearse

1. **Do not memorise the model answers.** Read one, close the file, and say the idea in your own words.
2. Record yourself for the first answer of each session. Listen for filler, speed, and sentence length.
3. Use the follow-up question every time. The follow-up is where memorised answers fail.
4. Mark each item after rehearsal:

| Mark | Meaning | Next action |
|---|---|---|
| ✅ | Clear, specific, under 75 seconds | Review in 3 days |
| 🟡 | Correct but generic or slow | Rehearse once more with a concrete example |
| 🔴 | Cannot answer without reading | Learn the underlying concept, then retry |

5. Prioritise 🔴 items by category weight: technical fundamentals and SQL first, then behavioural, then company fit.
