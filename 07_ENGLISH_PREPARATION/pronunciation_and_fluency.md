# Pronunciation and Fluency

**Purpose:** Improve intelligibility with short, repeatable drills.
**Created / last updated:** 31 October 2026
**Status:** Possible Indonesian-speaker patterns, not a diagnosis of Marchel. Respelling is approximate; listen to dictionary audio when available.

## 1. Ten-minute daily drill

2 minutes final consonants; 2 minutes contrasting sounds; 2 minutes technical word stress; 2 minutes shadow a short clear recording; 2 minutes record a project answer and listen. Accent removal is not the goal.

| Focus | Drill | What to notice |
|---|---|---|
| Final consonants | code / coat; save / safe; log / lock | Do not drop the ending or add a full extra vowel |
| TH sounds | think / sink; then / den | Tongue lightly near/between teeth; voiced in "then" |
| V / W | vest / west; vine / wine | V: teeth near lower lip; W: rounded lips |
| F / P | fan / pan; fine / pine | F has continuous air; P is a release |
| Consonant clusters | tests, scripts, requests | Slow down without adding "e" between every consonant |
| -ed endings | worked /t/; played /d/; tested /id/ | Extra syllable mainly after t/d sounds |
| Word stress | de-VEL-op-er; in-te-GRA-tion; au-then-ti-CA-tion | Stress changes clarity more than speed |
| Sentence stress | "I built the WEB app, not the HARDWARE." | Highlight the ownership boundary |
| Questions | "Could you clarify the SCOPE?" | Calm, not rushed or apologetic |

Technical words: database (DAY-tuh-bays, common variant); query (KWEER-ee); schema (SKEE-muh); queue (kyoo); cache (cash); SQL (letters S-Q-L or "sequel", both common); asynchronous (ay-SING-kruh-nuhs); architecture (AR-ki-tek-cher). Variants exist; clarity matters more than imitating one accent.

## 2. Ten graded tongue-twisters

Say slowly and accurately twice, then at natural speed. These are articulation exercises, not assessment questions.

1. Save the safe file.
2. We view the web view.
3. Five valid values.
4. Three thin threads.
5. The test passed; the task failed.
6. Six scripts send six requests.
7. Clean code keeps clear constraints.
8. The cached class count changed.
9. Three threads checked thirty transactions.
10. Verified versions prevent very vague validation.

## 3. Fluency without filler

Chunk by meaning: "The main risk / is duplicate processing. / I would prevent it / with a stable event key." Pause at the slash. Do not pause in the middle of every technical term.

Shadow 15–20 seconds of clear speech, then say the same idea in your own words. Record at a comfortable pace. If you cannot explain a phrase without the script, simplify it. Replace "basically, actually, you know" with a short silent pause.

## 4. Self-check

| Criterion | 1 | 3 | 5 |
|---|---|---|---|
| Intelligibility | Key words repeatedly misunderstood | Mostly clear | Technical terms clear without strain |
| Pace | Rushes or long word-by-word gaps | Some useful pauses | Natural chunks and steady pace |
| Repair | Gives up or pretends to understand | Asks for repetition | Clarifies the precise uncertain meaning |
| Content | Memorised sound without meaning | Main idea understandable | Answers follow-up in own words |

No score recorded until a sample is heard. Do not treat accent difference as low technical competence.
